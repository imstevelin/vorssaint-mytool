# 指定藍牙音訊裝置的連線修復

在「設定 → 輸出切換器 → 藍牙喇叭連線修復」：

1. 先連接需要修復的藍牙喇叭或耳機，清單會自動更新。
2. 勾選需要自動重啟的裝置，可選擇多台。
3. 開啟「連接指定裝置時自動重啟藍牙服務」。尚未授權時，使用既有的授權按鈕。

只有勾選的裝置成為預設音訊輸出，才會進入既有的重啟判斷。
未勾選、空清單或關閉開關時，均不會自動重啟。升級不會自動勾選任何裝置。
已選裝置離線後仍會保留名稱和選擇，也可以直接取消勾選。
剛勾選一台已連線的裝置不會立即重啟；之後的連線事件才會觸發。

裝置以 Core Audio UID 精確識別，名稱僅供顯示；改名不會選到別台同名裝置。
若系統為裝置重新分配 UID，請重新連接並選取新的項目，取消舊項目。
選擇可隨設定備份保存，匯入不含新欄位的舊備份不會清空本機選擇。

重啟仍會短暫中斷全部藍牙裝置。原有的重新連線防循環、啟動不重啟，
以及所有裝置共用的 30 分鐘最短間隔持續有效。
這項功能重啟 bluetoothd，不會刪除配對紀錄或快取檔案。
