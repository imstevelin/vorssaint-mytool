# Dynamic Island 小夥伴（1.0.9）

在「設定 → Dynamic Island → 小夥伴」選擇極簡、機器人、小貓、小狗、小熊、小狐狸或小兔。
所有角色使用白色單色輪廓與黑色表情，不再顯示配色選項。

待機及自主來訪全程維持原本的正面造型，避免在小顯示面積切換成難以辨識的側面。
小狗重新設計為圓潤幼犬臉、短垂耳、大眼睛與微笑，移除鼻口外框及側邊尾巴。
五款自訂動物依可見輪廓放大至外框約 98% 高度（原生圓臉為 84%），寬度最多為外框的 122%。
角色依放大後的可見輪廓及島的實際高度垂直置中，避免下方留白過多。
自主來訪約 26–36 秒，保留探頭、探索、邀請互動、回頭及嬉戲等移動橋段，
搭配眨眼、歪頭、呼吸、伸展與跳動；不再切換全身姿態或作立體轉身。
在預覽中重複按「來訪」可觀看不同橋段，「打個招呼」則在真正的島上出場。

各角色有不同的來訪偏好，不會連續重複同一故事。邀請互動時會停留等待，
將游標在角色上停留片刻可摸摸牠。閒置約一分鐘才會隱藏，原有頻率與反應開關仍有效。
待機動作遵循減少動態效果與低耗電設定，交由 Core Animation 播放。
