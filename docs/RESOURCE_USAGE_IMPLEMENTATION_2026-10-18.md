# 資源使用改善實作

本次以保留使用者體驗為優先，延續工作目錄原有功能、預設值與未提交修改。已依使用者要求替換 `/Applications/實用小工具.app` 並重新啟動供實測。

## 已實作

- **視窗記憶**：AX 查詢及通知註冊移至背景序列佇列；快取角色與視窗 ID 對應，動態重查可調整尺寸、最小化按鈕、modal 與全螢幕狀態。AX 通知會加速更新，仍保留原本 0.5 秒相容性補漏與五秒角色更新。拖曳時不查詢或移動視窗；套用前重查實際幾何。查詢期間發生的事件、程序／視窗 ID 變動及螢幕 transition 都會阻止過期結果套用。
- **非同步結果**：單一視窗變動只排除該視窗，避免整批工作餓死；不完整快照不能覆蓋完整配置。標題在查詢期間改變時，保留文件專屬還原機會並補查冷資料，避免先用通用尺寸再跳動。
- **保存**：同一輪學習及配置變動合併成一次背景保存；快照比較忽略單純 Z-order 改變，但保留原始匹配順序與精確幾何，不新增位置容差。最多一個保存工作在途，其餘合併成最新狀態；正常退出補存。
- **歷史配置**：SQLite 交易保存完整歷史；每螢幕熱快取以 256 個標題配置為預算，保護目前可見視窗、App 通用配置及尚未成功保存的版本。冷資料按需讀回，沒有以過期政策刪除舊文件配置。舊偏好設定只在交易成功後移除；資料庫不可用時保留／回退原本的完整偏好設定。遷移途中或磁碟保存失敗時，偏好設定中的新資料優先於較舊資料庫快照。
- **動態島**：同一個主佇列 turn 共用 WindowServer 快照，下一 turn 自動失效。維持原本 0.25 秒普通檢查、0.08 秒 overview 恢復檢查；沒有為省資源延後顯示／隱藏。
- **錄影**：維持 125 Hz、Double 精度及完整游標形狀／可見性／identity 順序。每 4,096 筆分段寫入私有暫存檔，最多四段寫入在途；正常錄影的應用程式樣本緩衝約 960 KiB 以內，不包括游標圖、OS 檔案快取與交接時整份軌跡。磁碟不可用、寫入失敗或寫入跟不上時改用記憶體，優先不丟樣本。停止時在主執行緒移除 AppKit monitor，整份讀回與離線封裝在背景進行。不可恢復的讀回失敗會保留已錄好的影片、顯示系統錯誤並留下暫存檔，不會默默回傳截短軌跡。
- **媒體轉檔**：以 AVFoundation readiness callback 驅動原本的音畫交錯邏輯，每軌最多保留一個待寫樣本；去除 2 ms 輪詢。維持編碼參數、方向、目標大小重試及取消行為，沒有透過降畫質省資源。
- **藍牙恢復**：以 CoreAudio 路由／裝置通知即時觸發，同時維持原本三秒補漏；即使通知註冊成功也不降低補漏頻率，避免驅動遺漏事件時讓恢復變慢。sudo 授權檢查移至背景；停止／重新啟用或路由變動時檢查 generation 與當前 UID，保留 cooldown 與重連防循環。授權期間不消耗另一裝置的恢復機會。
- **移除生命週期**：清除權限時暫停視窗 AX 工作；完整移除 App 前等待背景查詢與保存結束、關閉資料庫，並禁止結束程式時再次建立已移除的資料。AI 保存也有相同移除 barrier。
- **AI 日誌**：普通停用不再同步等候歷史掃描／保存；同一序列佇列保證保存、停止、重新啟用的先後順序。啟動目錄列舉可取消，正常退出才等待保存完成。

## 刻意保留的體驗

動畫保持 30 FPS，沒有加入自動降幀；視窗補漏、Mission Control 反應速度及錄影取樣率均不降低。沒有丟棄歷史配置，也沒有增加使用者必須操作的省電設定。系統監控、剪貼簿、縮圖容量上限及 EDR 心跳維持既有保護。

## 驗證

新增 `resource-usage` 測試群組，直接執行正式程式碼，涵蓋：

- 同 turn 快照共用與下一 turn 失效。
- AX 快取命中、逐 App 事件失效、角色補漏、動態不合格與關閉視窗。
- 過期幾何／回收視窗 ID 不套用、不阻塞其他 App。
- 一千多筆歷史配置交易保存、冷讀回、重開資料庫、Legacy size-only 相容及保存失敗。
- 熱快取清理不淘汰可見視窗或未保存版本。
- 12,000 筆完整游標樣本在正常、無暫存磁碟及部分寫入後磁碟滿的情況下維持精度與順序。
- 實際生成有聲測試影片，再以正式編碼路徑驗證有聲／無聲轉檔、時長、輸出大小、進度及途中取消。
- 正式視窗掃描一次保存多視窗、只切換 Z-order 不保存、延後冷標題還原仍保留一次還原機會。

另外更新游標 monitor 的停止邊界檢查；修正三個原本已與此工作目錄亮度預設值衝突的測試期待，未更改功能預設值。

最終建置與完整回歸結果記錄於本文件後續段落。這些測試不能替代實際外接螢幕重接、不同 App 的 AX 相容性、實體藍牙音訊及長時間錄影。新版本已安裝啟動，尚未完成相同條件下的前後資源量測，沒有宣稱已實測降低多少 CPU／耗電。
