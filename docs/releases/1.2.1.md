# 實用小工具 1.2.1 — 2026-11-02

本機正式修正版，build 14，Apple Silicon。使用者授權將全部未合併修改與分支整合、推送到 main，並安裝最新正式 App；本次不另外建立公開 Release 或覆寫 v1.2.0 資產。

## 修改

- 選單改用 SystemOutputControl，顯示 DDC 螢幕音量與讀回更新。
- DDC 失敗不重送原生按鍵；仍保留實際讀回、失敗回退與錯誤資訊。
- 輸出切換成功後退役舊音量控制，立即清除舊能力並同步媒體鍵。
- 排隊或失敗的舊按鍵不能誤調切換後的新輸出。
- 版本保護升為 1.2.1／14，保留 fork 不觸發官方支援邀請的決策。

## 範圍與驗證

開始時工作目錄乾淨；PR #11 是唯一未合併的 fork 功能分支，其餘歷史分支提交已包含在主線。本輪不把未整合的官方 upstream 當作 fork 未合併工作。

完整回歸、雙工具鏈 CI、正式建置、selftest、strict deep codesign 與備份安裝的最終結果，以 PR #11 和本機交付紀錄為準。實體螢幕／鍵盤與其他裝置硬體相容性不能由自動測試代替。
