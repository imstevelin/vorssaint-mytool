# 實用小工具 1.3.0 — 2026-11-12

本輪本機正式更新，build 15，Apple Silicon。整合官方 v3.4.4 的 228 筆提交；使用者要求安裝本機，沒有要求建立公開 tag／GitHub Release。

## 官方新增功能與改善

- 支援螢幕內建喇叭音量、按鍵步進及上下限，另提供可讀 DDC 螢幕的軟體調暗選擇。
- 自動滾動截圖與獨立快捷鍵；GIF 匯出可選幀率及縮放，順序解碼與 GPU 重用降低耗時／記憶體。
- 修飾鍵加滾輪加速、Pinch Zoom；視窗切換器新增所有視窗快捷鍵、更多欄數及關閉 hover 選取選項。
- 貼齊視窗拖離可恢復先前尺寸，視窗排列可為幕前調度保留空間。
- Claude Code 帳號選擇、帳號身分與限制顯示；島的播放器可加音量列、行事曆倒數可更早開始。
- Quit apps 面板；App 移到垃圾桶後可選擇檢查殘留，移除工具加入全選與 Homebrew 狀態保護。
- CLI 設定匯入／匯出與唯讀 XDG 設定檔；剪貼簿保留天數、來源圖示、記住視窗位置，以及圖片格式／大小選擇。
- 修正早期 Sonoma 啟動、Super Key、麥克風多聲道靜音、螢幕睡醒恢復、mixer、全螢幕與通知；Homebrew 使用預設終端機。

新增選項遵循既有功能可用性與預設啟用選擇，不替使用者一律開啟。

## 保留與調整的客製行為

- fork 品牌、bundle ID、偏好遷移及手動更新；版號為 1.3.0，而非官方 3.4.4。
- 原生／虛擬 HiDPI、顯示恢復 helper、ICC／更新率驗證與對應桌面的 OSD。
- 每顯示器視窗記憶、最新手動操作優先、新視窗自然排列及螢幕座標就緒後的提早還原。
- CoreAudio 優先／DDC 備援、既有螢幕音量選擇、輸出切換退役舊操作，以及 DDC 失敗不重送原生按鍵。
- 每次接受的音量操作獨立回饋，保留原生例外防護；全螢幕與 hover 隱藏島仍使用中央卡片。
- 五種自訂小夥伴與游標／事件互動、減少動態與不可見暫停。
- 官方 Claude profile 與 fork 掃描取消一起整合；保留 AI 保存順序與錄影游標精度。
- XDG 設定檔隔離為 `~/.config/vorssaint-imstevelin/settings.plist`，Developer 使用 `vorssaint-imstevelin-dev`。
- 原有指定藍牙裝置修復、離線選擇、30 分鐘冷卻及防循環保留；修復設定標題也可由搜尋找到。
